# Quick Start

The fastest path to a working Cortex install — five commands.

## Prerequisites

- **Python 3.10+**
- **git**

## Setup

```bash
git clone https://github.com/JaySmith/Cortex-AI.git cortex-ai
cd cortex-ai
cortex bootstrap
cortex install ~/Cortex       # or any path; creates the vault if needed
cortex status                 # verify everything is healthy
```

That's it. You have working encoded output in `~/Cortex/_sync/encoded/`.

## First Memory Write

Write a note from the CLI:

```bash
cortex memory write --title "My Preferences" --type feedback --tier core
```

Then rebuild:

```bash
cortex encode
```

The note is now part of your agent's always-on context.

## First Search

```bash
cortex memory search "preferences"
```

## What Just Happened

```
~/Cortex/
├── _sync/
│   ├── cortex.yaml              ← config (generated by install)
│   └── encoded/                 ← generated agent context
│       ├── opencode/
│       │   └── core-context.md  ← always-loaded instructions
│       ├── skills/*/reference.md ← lazy per-skill knowledge
│       ├── projects/*.md        ← lazy per-project context
│       └── memory.json          ← structured index
├── feedback/
│   └── my-preferences.md        ← the note you just wrote
└── ...
```
