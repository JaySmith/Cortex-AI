# Development Preferences

Default to **Node.js + TypeScript** for new work unless the task calls for something else.

## Rules
- Prefer `.ts`/`.tsx` files and TypeScript tooling.
- Use `npm` or `pnpm` for package management.
- Modern ES2022+ syntax with strict mode enabled.

This note is `tier: core`, so it is concatenated into `core-context.md` and loaded
by the agent on every session.
