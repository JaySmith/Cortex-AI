# Quick Start

The fastest path to a working Cortex install — five commands.

## Prerequisites

- **Python 3.10+**
- **git**

## Setup

```bash
git clone https://github.com/JaySmith/Cortex-AI.git cortex-ai
cd cortex-ai
cortex bootstrap
cortex install ~/cortex-ai    # or any path; creates the vault if needed
cortex status                 # verify everything is healthy
```

That's it. You have working encoded output in `~/cortex-ai/_sync/encoded/`.

## First Memory Write

Write a note from the CLI:

```bash
cortex memory write --title "My Preferences" --type feedback --tier core --body "I prefer TypeScript strict mode"
```

The note is now part of your agent's always-on context (encoding auto-triggers
in the background).

## First Search

```bash
cortex memory search "preferences"
```

## What Just Happened

```
~/cortex-ai/
├── _sync/
│   ├── cortex.yaml              ← config (generated by install)
│   └── encoded/                 ← generated agent context
│       ├── core-context.md      ← always-loaded instructions
│       ├── projects/*.md        ← lazy per-project context
│       └── memory.json          ← structured index
├── feedback/
│   └── my-preferences.md        ← the note you just wrote
└── ...
```
